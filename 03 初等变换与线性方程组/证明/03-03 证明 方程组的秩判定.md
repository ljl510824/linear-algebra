# 03-03 证明 方程组的秩判定

[[03-03 线性方程组的判定]] · [[补充 证明与基础阅读导航]]

## 从列组合证明有解条件

设 $A=(a_1,\ldots,a_n)$，则
$$Ax=b\iff x_1a_1+\cdots+x_na_n=b
\iff b\in\operatorname{col}A.$$
加入一列 $b$ 不增加张成空间，恰好等价于拼接矩阵的秩不变：
$$Ax=b\text{ 有解}\iff r(A)=r(A\mid b).$$
从消元看，若常数列产生额外主元，就出现 $(0,\ldots,0\mid c)$ 且 $c\ne0$，对应矛盾方程 $0=c$。

## 为什么自由参数正好有 n-r 个

有解时，设主元变量为 $x_{p_1},\ldots,x_{p_r}$，其余 $n-r$ 个为自由变量。行最简形的每个非零行都能写成
$$x_{p_i}=d_i-\sum_{j\in F}c_{ij}x_j.$$
任取自由变量便唯一确定所有主元变量，且零行不增加条件。因此：

```text
r = n => 没有自由变量 => 只有一个解
r < n => 至少一个自由变量可任取实数 => 无穷多个解
```

齐次时 $d_i=0$，永远可取零解；$r=n$ 时仅零解；$r<n$ 时令某自由变量为 $1$ 就得到一个非零解。

## 为什么不会恰有有限多个但多于一个解

若 $u\ne v$ 都满足 $Ax=b$，则任意实数 $t$ 都有
$$A[u+t(v-u)]=Au+t(Av-Au)=b.$$
不同 $t$ 产生不同向量，所以一旦有两个不同解，就有无穷多个。这里依赖实数域（或其他无限域），不能直接推广到只有有限元素的域。

## 多个右端同时求解

$AX=B$ 当且仅当 $B$ 的每一列都可由 $A$ 的列表示，即
$$AX=B\text{ 有解}\iff\operatorname{col}B\subseteq\operatorname{col}A
\iff r(A\mid B)=r(A).$$
行满秩 $r(A)=m$ => 列空间是整个 $\mathbb R^m$ => 每个右端都有解。列满秩 $r(A)=n$ => 齐次只零解 => 有解时唯一。长方阵的这两个条件不能混用。
