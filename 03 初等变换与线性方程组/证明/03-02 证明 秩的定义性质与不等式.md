# 03-02 证明 秩的定义性质与不等式

[[03-02 矩阵的秩与等价]] · [[补充 证明与基础阅读导航]]

## 从子式定义到主元个数

选 $k$ 行、$k$ 列的方式分别有 $\binom mk,\binom nk$ 种，因此 $k$ 阶子式有 $\binom mk\binom nk$ 个。取不到超过 $\min(m,n)$ 阶的子式，故 $0\le r(A)\le\min(m,n)$。转置把每个子式变为其转置，值不变，所以 $r(A^T)=r(A)$。

一个非零 $k$ 阶行列式沿某行展开，至少一个代数余子式非零，否则展开值为零。因此存在非零 $k$ 阶子式 => 存在非零 $k-1$ 阶子式 => 依次存在所有更低阶非零子式。于是
$$r(A)\ge s\iff\text{存在非零 }s\text{ 阶子式}.$$

## 初等变换为什么不改变秩

行对换只重排被选行及相应子式，倍乘只乘非零因子。对于倍加 $r_i\leftarrow r_i+kr_j$，考察任意变换后的 $t$ 阶子式：

- 未选第 $i$ 行：不变。
- 同时选了第 $i,j$ 行：额外项有重复行，为零。
- 选了第 $i$ 行但没选第 $j$ 行：由单行可加性，变为两个原矩阵 $t$ 阶子式的线性组合（行次序可能贡献一个负号）。

因此原来所有 $t$ 阶子式为零 => 变换后也全零。反向操作同样成立，故最大非零阶数不变。列变换由转置得到。

阶梯形有 $r$ 个非零行，选这些行的主元列所得子式是对角元非零的上三角式，故秩至少 $r$；任何更高阶子式包含零行，故秩至多 $r$。因此秩等于主元数。标准形中的 $r$ 也就是原矩阵的秩。

$$A,B\text{ 同型且同秩}
\Rightarrow\text{可化为同一标准形}
\Rightarrow A\sim B.$$
反向由秩不变成立。方阵满秩等价于唯一的 $n$ 阶子式非零，因此等价于可逆。

## 子式秩、列秩、行秩相等

将 $A$ 行化简为 $R=PA$。可逆 $P$ 保留列间所有线性关系：
$$Ac=0\iff Rc=0.$$
阶梯形主元列无关，而且其他列都在它们的张成空间中。因此列向量组的最大无关个数是 $r$。取转置并利用 $r(A)=r(A^T)$，得到行秩同样为 $r$。这也给出了第四章使用的“秩等于张成空间维数”。

## 常用秩不等式

以下把秩看成列空间维数，维数基础见 [[04-03 证明 极大无关组与秩]]。

拼接矩阵的列空间为 $U+V$，其中 $U=\operatorname{col}A,V=\operatorname{col}B$。它包含 $U,V$，而两组基合起来可以生成 $U+V$，故
$$\max(r(A),r(B))\le r(A\mid B)\le r(A)+r(B).$$

$A+B$ 的每列都属于 $U+V$，所以 $r(A+B)\le r(A)+r(B)$。$AB$ 的每列都在 $A$ 的列空间内，故 $r(AB)\le r(A)$；取转置再用同一结论得 $r(AB)\le r(B)$。因此
$$r(AB)\le\min(r(A),r(B)).$$

可逆乘子有两侧不等式：
$$r(PA)\le r(A)=r(P^{-1}PA)\le r(PA)
\Rightarrow r(PA)=r(A).$$
右乘同理。

若 $AB=0$，$B$ 的所有列属于 $\ker A$，而自由变量构造给出 $\dim\ker A=n-r(A)$（证明见 [[04-04 证明 解空间与通解结构]]），所以
$$r(B)\le n-r(A)\Rightarrow r(A)+r(B)\le n.$$

## 满秩因子与伴随矩阵

若 $A$ 列满秩，$Ax=0$ 只有零解，所以映射 $x\mapsto Ax$ 不会把非零线性关系压没：
$$ABc=0\iff Bc=0\Rightarrow r(AB)=r(B).$$
或者将 $A$ 行化简为 $\begin{pmatrix}I\\0\end{pmatrix}$，结论立即成立。行满秩右乘保秩由转置得到。

$n\ge2$ 时：
- $r(A)=n$ => $A^*=\det(A)A^{-1}$ 可逆 => $r(A^*)=n$。
- $r(A)\le n-2$ => 所有 $n-1$ 阶子式为零 => $A^*=0$。
- $r(A)=n-1$ => 至少一个 $n-1$ 阶子式非零 => $A^*\ne0$；又 $AA^*=0$，各列都在一维 $\ker A$ 中 => $r(A^*)\le1$ => $r(A^*)=1$。

> [!example] 一百条读数也可能只有一个独立信息
> 若所有传感器都只是同一温度 $t$ 的不同倍数，读数为 $y=ut$。输出虽有一百个分量，却只能沿向量 $u$ 的一条直线变化，秩为 $1$。重复读数有助于抗噪，但不会让一个未知量变成一百个独立未知量。
