# 05-07 惯性定律与正定二次型

[[00 线性代数总览]] · [[第五章 相似矩阵与二次型]] · [[阅读与使用说明]]

## 正定、负定与半定

对实对称 $A$，二次型 $f=x^TAx$：

| 类型 | 对所有非零 x 的条件 |
| --- | --- |
| 正定 | $f>0$ |
| 负定 | $f<0$ |
| 半正定 | $f\ge0$ |
| 半负定 | $f\le0$ |
| 不定 | 有些非零向量使其为正，另一些使其为负 |

## 惯性定律

若两种**可逆**线性变换都把同一实二次型化为标准形，则正系数个数相同，负系数个数也相同。它们分别称正惯性指数 $p$、负惯性指数 $q$；秩为 $p+q$，零系数个数为 $n-p-q$。原稿还回顾：正交化的标准形系数为特征值，一般配方法的标准形系数未必是特征值。

**补例 1：** 六元二次型某标准形为
$$3y_1^2+2y_2^2-y_3^2+5y_4^2-y_5^2+0y_6^2.$$
求惯性指数、秩和方阵合同类。

> [!success] 补充结论
> $p=3,q=2,R(A)=5$，与 $\operatorname{diag}(1,1,1,-1,-1,0)$ 合同。

## 正定的等价条件

> [!important] 对实对称 n 阶矩阵 A
> 下列条件等价：
> - 所有非零 $x$ 都有 $x^TAx>0$；
> - 任一标准形的所有系数都正；
> - 正惯性指数为 $n$；规范形所有系数为 1；
> - 所有特征值都正；
> - 全部顺序主子式都正。

顺序主子式：取左上角前 $k$ 行、前 $k$ 列得到的行列式 $\Delta_k$。

## 希尔维特判据

正定当且仅当 $\Delta_1,\ldots,\Delta_n$ 全正。
负定当且仅当奇数阶顺序主子式负、偶数阶正，即 $(-1)^k\Delta_k>0$。

> [!warning] 补充：半正定不能照搬严格判据
> “顺序主子式都非负”不足以判定半正定。例如 $\operatorname{diag}(0,-1)$ 的顺序主子式都为零，却不是半正定。半正定可用所有特征值非负，或所有主子式非负来判定。

**例 17（原稿列题）：** 判断 $f=-5x^2-6y^2-4z^2+4xy+4xz$ 的定性。

> [!success] 补充计算
> $A=\begin{pmatrix}-5&2&2\\2&-6&0\\2&0&-4\end{pmatrix}$，顺序主子式为 $-5,26,-80$，满足负定判据，所以负定。

> [!example] 补充：唯一最小值与稳定代价
> 若 $Q$ 正定，代价 $J(x)=\frac12x^TQx-c^Tx$ 有唯一全局最小点，满足 $Qx=c$。完成平方可得 $J(x)=\frac12(x-Q^{-1}c)^TQ(x-Q^{-1}c)-\frac12c^TQ^{-1}c$。若仅半正定，可能有多个最小点，也可能因线性项而无下界，必须再检查条件。关联 [[03-03 线性方程组的判定]]。
