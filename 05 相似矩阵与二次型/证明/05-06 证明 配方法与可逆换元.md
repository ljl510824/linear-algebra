# 05-06 证明 配方法与可逆换元

[[05-06 配方法化标准形]] · [[补充 证明与基础阅读导航]]

## 有非零平方项时

若 $a_{11}\ne0$，将与 $x_1$ 有关的项单独拿出：
$$f=a_{11}x_1^2+2x_1\sum_{j>1}a_{1j}x_j+g(x_2,\ldots,x_n).$$
配方得
$$f=a_{11}\left(x_1+\sum_{j>1}\frac{a_{1j}}{a_{11}}x_j\right)^2
+g-\frac1{a_{11}}\left(\sum_{j>1}a_{1j}x_j\right)^2.$$
令括号内为 $y_1$，其他变量保持。这是对角元全为 $1$ 的三角换元，可直接反解，所以可逆。剩下的二次型少一个变量，递归处理即可。若非零平方项不在第一个变量，先交换变量，交换也可逆。

## 没有平方项时

若所有平方项系数为零而二次型不为零，必有某个混合系数 $a_{ij}\ne0$。令
$$x_i=u+v,\qquad x_j=u-v,$$
其他变量不变，则 $2a_{ij}x_ix_j=2a_{ij}u^2-2a_{ij}v^2$，产生非零平方项。这个二元换元的行列式为 $-2\ne0$，可逆。回到上一种情况继续配方。若所有项都为零，已经是标准形。

每一步不是减少剩余变量数，就是先制造一个可处理的平方项，因此有限步后终止。所有换元可逆，乘积仍可逆，于是配方法确实给出合同变换。

## 矩阵形式：舒尔补

对称矩阵分块为 $A=\begin{pmatrix}a&b^T\\b&C\end{pmatrix}$，$a\ne0$。上述配方就是
$$f=a(x_1+a^{-1}b^Tx')^2+x'^T(C-a^{-1}bb^T)x'.$$
剩余矩阵 $C-a^{-1}bb^T$ 称舒尔补。这把第一章的爪形行列式、第二章的分块消元和本章配方联系起来。

> [!example] 长公式背后的“最佳响应”
> 若 $a>0$，固定其他变量 $x'$ 后，代价关于 $x_1$ 在 $x_1=-a^{-1}b^Tx'$ 处最小。配掉第一个平方，等于让一个调节量先自动选择最佳响应；剩下的舒尔补描述其他变量仍需承担的代价。若 $a<0$，这一点反而是该方向的最大值，不能当作最小化步骤。

## 验证换元的可靠方法

```text
配方得到 y = Tx
=> 检查 T 可逆
=> 明确 x = T⁻¹y，记 C = T⁻¹
=> 计算 CᵀAC
=> 与写出的对角系数逐项比较
```

“写出了几个平方”还不够；只有换元可逆，才能保证没有丢失变量和原来的全部取值。
