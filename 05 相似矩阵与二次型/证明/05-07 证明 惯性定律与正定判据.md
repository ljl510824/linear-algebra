# 05-07 证明 惯性定律与正定判据

[[05-07 惯性定律与正定二次型]] · [[补充 证明与基础阅读导航]]

## 惯性为什么不依赖配方方式

设某标准形有 $p$ 个正系数、$q$ 个负系数。正系数坐标对应的 $p$ 维子空间上，除零点外二次型严格为正。

假设另一标准形只有 $p'<p$ 个正系数。把上述 $p$ 维子空间换到另一组坐标，要求其中的前 $p'$ 个正系数坐标全为零，这给出至多 $p'$ 个齐次线性约束。未知自由度为 $p$，所以必有非零向量满足这些约束。

这个向量一方面属于原来的正子空间，函数值应为正；另一方面在新坐标中只有负项和零项，函数值应不大于零，矛盾。所以 $p\le p'$。交换两种标准形，得到 $p'=p$。对 $-f$ 重复论证，负系数个数也相同。

因此正、负惯性指数是固定的。标准形矩阵的秩是非零对角元数，合同保持秩，故
$$r(A)=p+q,\qquad \text{零系数数}=n-p-q.$$
两个实对称矩阵合同，当且仅当它们阶数及正负惯性指数相同：必要性已证；充分性把两者都化成相同的 $\operatorname{diag}(I_p,-I_q,0)$，再复合可逆换元。

## 正定等价条件

用正交对角化写
$$x^TAx=\sum_i\lambda_i y_i^2,\qquad x=Qy.$$
所有 $\lambda_i>0$ => 非零 $y$ 至少一项正 => 正定。反向若某 $\lambda_j\le0$，取 $y=e_j$ 就违反正定，所以
$$A\text{ 正定}\iff\text{所有特征值正}\iff p=n.$$
惯性定律进一步说明，这等价于任一标准形所有系数正、规范形为 $\sum_i z_i^2$。把正改为负得到负定；非严格不等式给出半正定、半负定；正负特征值同时存在则不定。

## 希尔维特判据的必要性

若 $A$ 正定，取前 $k$ 个坐标任意、其余为零，得到左上角主子矩阵 $A_k$ 也正定。由刚证明的特征值判据，$A_k$ 的所有特征值正，因此
$$\Delta_k=\det A_k>0.$$

## 希尔维特判据的充分性

用维数归纳。$n=1$ 显然。设各顺序主子式均正，把
$$A=\begin{pmatrix}a&b^T\\b&C\end{pmatrix},\quad a=\Delta_1>0.$$
配方得到
$$x^TAx=a(x_1+a^{-1}b^Tx')^2+x'^TSx',\qquad S=C-a^{-1}bb^T.$$
对每个前 $k+1$ 阶块做同样消元，行列式为 $a$ 乘 $S$ 的前 $k$ 阶主子式，因此
$$\det S_k=\Delta_{k+1}/a>0.$$
由归纳假设 $S$ 正定。若 $x'\ne0$，第二项严格正；若 $x'=0,x\ne0$，第一项严格正。因此 $A$ 正定。

这个过程还给出无换行的 $LDL^T$ 分解，对角枢轴为
$$d_k=\Delta_k/\Delta_{k-1},\quad\Delta_0=1.$$
所以顺序主子式全正，正好意味着每一步配出的平方系数都正。负定等价于 $-A$ 正定，其前 $k$ 阶主子式为 $(-1)^k\Delta_k$，得到原文交替符号判据。

## 半正定为什么要求所有主子式

半正定时任意主子矩阵也半正定，特征值非负，所以全部主子式非负。

反向，设所有主子式非负。对任意 $\varepsilon>0$，每个前 $k$ 阶块满足
$$\det(A_k+\varepsilon I)
=\sum_{S\subseteq\{1,\ldots,k\}}\varepsilon^{k-|S|}\det A_k[S,S]>0.$$
公式由行列式对列的多线性展开得到：选 $\varepsilon I$ 的列会把对应行列锁定，剩下就是一个主子式。空集项为 $\varepsilon^k>0$，其余项非负。因此 $A+\varepsilon I$ 的顺序主子式全正，依希尔维特判据它正定。令 $\varepsilon$ 趋于零，
$$x^T(A+\varepsilon I)x>0\Rightarrow x^TAx\ge0,$$
所以 $A$ 半正定。

只检查顺序主子式不够：$\operatorname{diag}(0,-1)$ 的两个顺序主子式均为零，但取 $(0,1)^T$ 得负值。

> [!example] 长证明之后：为什么“每个误差都罚一点”能消除不唯一
> 对任何实矩阵 $X$，$X^TX$ 半正定，但重复的输入列可能使参数不唯一。加入 $\varepsilon I$，$\varepsilon>0$：
> $$z^T(X^TX+\varepsilon I)z=\|Xz\|^2+\varepsilon\|z\|^2>0\quad(z\ne0).$$
> 因此新代价严格正定，有唯一最优参数。这是平方惩罚的一条基本原理；它改善唯一性，同时也改变了原来的优化目标。

## 二次代价为何有唯一最小值

设 $Q$ 正定，$J(x)=\frac12x^TQx-c^Tx$，令 $x_*=Q^{-1}c$。展开可验证
$$J(x)=\frac12(x-x_*)^TQ(x-x_*)-\frac12c^TQ^{-1}c.$$
第一项非负，且仅 $x=x_*$ 时为零，所以最小点唯一。

若 $Q$ 只半正定，正交对角化后
$$J(y)=\sum_i\left(\frac12\lambda_i y_i^2-d_iy_i\right).$$
$\lambda_i=0$ 但 $d_i\ne0$ => 沿该方向无下界；所有零特征值方向都满足 $d_i=0$ => 对应变量任意，最小点通常不唯一。这等价于 $c\in\operatorname{col}Q$。若存在负特征值，沿其方向二次负项主导，函数无下界。
