# 05-04 证明 实对称矩阵的谱定理

[[05-04 实对称矩阵的正交对角化]] · [[补充 证明与基础阅读导航]]

## 先说明证明依赖

> [!note] 本证明使用的基础事实
> 连续函数在有限维空间的单位球面上能取到最大值；一元可微函数在内部极值处导数为零。若尚未学习这些分析知识，可以先接受这两条事实，下面的线性代数步骤仍可逐步核对。

设 $A=A^T$ 为实矩阵。函数 $q(x)=x^TAx$ 在单位球面上连续，因此存在单位向量 $u$ 使它取最大值 $\lambda=u^TAu$，这个 $\lambda$ 是实数。

## 第一步：一定存在一个实特征向量

任取与 $u$ 垂直的单位向量 $v$，考察单位圆上的曲线 $x(t)=u\cos t+v\sin t$。$q(x(t))$ 在 $t=0$ 取极大值，展开并求导得
$$0=\left.\frac{d}{dt}q(x(t))\right|_{t=0}=2v^TAu.$$
因此 $Au$ 与所有垂直于 $u$ 的向量垂直，只能沿 $u$ 方向；再与 $u$ 取内积，系数为 $\lambda$，于是 $Au=\lambda u$。一维时结论直接成立，不需选 $v$。

## 第二步：垂直补空间仍被 A 保留

若 $w\perp u$，利用对称性：
$$u^TAw=(Au)^Tw=(\lambda u)^Tw=0.$$
所以 $Aw$ 仍在 $u^\perp$ 中。把 $u$ 扩充为标准正交基，在此基下矩阵成为
$$\begin{pmatrix}\lambda&0\\0&A_1\end{pmatrix},\qquad A_1=A_1^T.$$
对维数更小的 $A_1$ 重复相同步骤，归纳得到完整标准正交特征向量组。因此存在实正交 $Q$，
$$Q^TAQ=\operatorname{diag}(\lambda_1,\ldots,\lambda_n).$$

## 第三步：全部结论一起得到

- 对角元都是实数，且构成全部特征值，所以实对称矩阵全部特征值实。
- 若 $Au=\lambda u,Av=\mu v$，对称性给出
  $$\lambda u^Tv=(Au)^Tv=u^TAv=\mu u^Tv.$$
  $\lambda\ne\mu$ => $u^Tv=0$，不同特征值的向量正交。
- 已得到 $n$ 个无关特征向量，每个特征值的几何重数必等于代数重数 $k$，故 $r(\lambda I-A)=n-k$。
- 同一特征空间内进行施密特法，只取原向量的线性组合，仍留在该特征空间，因此不破坏特征向量性质。

```text
实对称
=> 能找到一个实单位特征向量
=> 其垂直补空间仍保持不变
=> 在更小空间重复
=> 获得整组标准正交特征向量
=> 正交对角化
```

## 补充：谱分解与主轴

若 $Q=(q_1,\ldots,q_n)$，则
$$A=Q\Lambda Q^T=\sum_i\lambda_iq_iq_i^T.$$
作用于 $x$ 时，先取其在每个正交方向上的分量 $q_i^Tx$，再分别乘 $\lambda_i$，最后相加。二次型也随之成为
$$x^TAx=\sum_i\lambda_i(q_i^Tx)^2.$$

> [!example] 长证明之后：一团数据为何有“最长方向”
> 对中心化样本组成的数据矩阵 $X$，取 $S=X^TX/m$。$S$ 对称且 $z^TSz=\|Xz\|^2/m\ge0$。单位方向 $z$ 上的平均平方投影为 $z^TSz$。写成特征基坐标后，
> $$z^TSz=\sum_i\lambda_i c_i^2,\qquad\sum_i c_i^2=1,$$
> 它是特征值的加权平均，因此最大值是最大特征值，对应方向就是数据最分散的主轴。这里用的是分母 $m$ 的描述性方差约定；改成 $m-1$ 只整体缩放特征值，不改主轴方向。
