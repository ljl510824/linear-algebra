# 直觉01 向量是动作与坐标

[[3B1B 线性代数的本质导览]] · [[04-01 向量线性组合与等价]]

> 同一个向量可以画成箭头，也可以写成有序数列；加法与数乘把这两种语言连接起来。

## 先看图，再给动作命名

左图中，$u=(2,1)^T$ 表示向右 2、向上 1；接着走 $v=(-1,2)^T$，终点便是 $(1,3)$。把 $v$ 的箭头平移到 $u$ 的末端，是在表示“相同位移接着发生”。右图的 $-1.5u$ 先翻转方向，再把长度变为 1.5 倍。

```text
位移相接 => 对应分量相加
整体伸缩 => 每个分量乘同一个数
选择一组基 => 才能把抽象向量写成具体坐标
```

$$u+v=\begin{pmatrix}2+(-1)\\1+2\end{pmatrix}
=\begin{pmatrix}1\\3\end{pmatrix},\qquad
-\frac32u=\begin{pmatrix}-3\\-\frac32\end{pmatrix}.$$

这里有三个层次：**对象**是位移，**图像**是箭头，**坐标**是相对于所选基的数字。更换基以后，位移可以不变而坐标改变，见 [[直觉13 换基是更换坐标语言]]。

## 为什么“先加再变换”值得关心

若一个规则 $T$ 满足

$$T(u+v)=T(u)+T(v),\qquad T(cu)=cT(u),$$

那么任意有限线性组合都能逐项处理：

$$T\!\left(\sum_i c_i v_i\right)=\sum_i c_iT(v_i).$$

**理由：** 先用加法保持性把求和拆开，再对每一项用数乘保持性。这个小结论就是“只跟踪基向量”的依据，下一步看 [[直觉03 矩阵怎样移动空间]]。

> [!example] 编辑补充 · 一天的用量可以先汇总再计算
> 用三维向量记录一天的三种原料用量。上午用量 $u$、下午用量 $v$，全天用量是 $u+v$；按同一配方生产两批，相应理论用量是 $2u$。若损耗随批次变化，实际模型还须增加损耗项，不能直接假定所有过程都线性。

> [!warning] 坐标相同不等于物理含义相同
> “温度、销量、距离”可以并列存成数列，但未经单位约定，直接计算它们的欧氏长度往往没有明确意义。把数据装进向量，是建模的开始；选什么尺度、允许哪些运算，还要由问题决定。

## 本节最小词典

| 名词 | 基础含义 |
| --- | --- |
| 标量 | 用来数乘向量的数；本组补充默认取实数 |
| 零向量 | 加到任何向量上都不改变结果的向量；在任意基下坐标全为零 |
| 坐标分量 | 向量按一组有序基展开时的系数 |
| 线性规则 | 同时保持向量加法和标量乘法的映射 |
