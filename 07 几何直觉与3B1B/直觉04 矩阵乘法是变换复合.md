# 直觉04 矩阵乘法是变换复合

## 从右向左读乘积

$$R=\begin{pmatrix}0&-1\\1&0\end{pmatrix},\qquad
S=\begin{pmatrix}1&1\\0&1\end{pmatrix}.$$

$R$ 是逆时针旋转 $90^\circ$，$S$ 是水平剪切。图中取同一输入 $v=(1,1)^T$：

$$v\xrightarrow{S}(2,1)^T\xrightarrow{R}(-1,2)^T,$$
$$v\xrightarrow{R}(-1,1)^T\xrightarrow{S}(0,1)^T.$$

$$RS=\begin{pmatrix}0&-1\\1&1\end{pmatrix}
\ne SR=\begin{pmatrix}1&-1\\1&0\end{pmatrix}.$$

两幅图的虚线只连接同一个向量在各步骤的位置；蓝色网格展示相应复合变换的最终作用。

```text
(AB)x = A(Bx)
输入 x => 先执行 B => 再执行 A => 输出
矩阵的书写次序，与动作发生次序相反
```

## 列公式与结合律为什么自然

第 $j$ 个标准基向量经过 $B$ 后变成第 $j$ 列 $b_j$，再经过 $A$ 后变成 $Ab_j$，所以

$$AB=[Ab_1\ \cdots\ Ab_n],\qquad
(AB)_{ij}=\sum_k a_{ik}b_{kj}.$$

对所有 $x$，若维数相容，则

$$((AB)C)x=A(B(Cx))=(A(BC))x.$$

把 $x$ 依次取成全部标准基向量，左右矩阵的每一列都相同，故 $(AB)C=A(BC)$。结合律只是改变分组，没有交换动作次序。

> [!example] 编辑补充 · 图像处理中“先拉宽”和“先转向”
> 把一个水平较长的图标拉宽后再旋转，和先旋转后沿屏幕水平方向拉宽，一般会得到不同形状。实现多步变换时，可以先把矩阵合并，随后对每个像素或顶点只乘一次复合矩阵；还需另行处理采样与插值。

> [!warning] 一个向量相同，不代表两个变换相同
> 验证 $ABv=BAv$ 对某个特殊 $v$ 成立，不能推出 $AB=BA$。比较所有基向量的像才足够。反过来，要反驳矩阵相等，只需找到一个输出不同的输入。

## 本节最小词典

**复合**是先后应用两个映射；**单位矩阵**表示恒等映射；**可交换**指 $AB=BA$。可交换是额外性质，结合律则对维数相容的矩阵总成立。
