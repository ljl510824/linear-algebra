# 04-02 证明 线性相关的判别与增删规律

[[04-02 线性相关与线性无关]] · [[补充 证明与基础阅读导航]]

## 相关为什么等价于至少一个向量可被其余表示

若 $\sum_i c_ia_i=0$ 且系数不全为零，选 $c_j\ne0$：
$$a_j=-\sum_{i\ne j}\frac{c_i}{c_j}a_i.$$
反向若一个向量由其余表示，移到同一边，其自身系数为 $1$，得到非平凡的零组合。单个零向量相关、单个非零向量无关也由定义立即得到。

对于两个向量，若都非零，相关当且仅当其中一个是另一个的倍数。若含零向量也相关。应把“成比例”理解为至少一个可以由另一个倍乘得到，不能固定只允许某一方向表示而漏掉零向量情形。

## 相关性与秩

$A=(a_1,\ldots,a_m)$ 时，
$$\sum_i c_ia_i=0\iff Ac=0.$$
只有零系数解 => $r(A)=m$ => 无关；有非零系数解 => $r(A)<m$ => 相关。特别地，$n$ 个 $n$ 维向量无关当且仅当行列式非零；$m>n$ 时 $r(A)\le n<m$，必相关。

## 增删向量与增删分量

某子组相关，把它的非零关系补上零系数，就得到整组的非零关系 => 整组相关。取逆否命题，整组无关 => 每个子组无关。

增加分量后的关系如果为零，删去新增分量后仍为零。所以截短后无关 => 原长向量组无关；长向量组相关 => 截短后相关。反向不成立：$(1)$、$(1)$ 相关，但补成 $(1,0)^T,(1,1)^T$ 后无关。

## 添一个向量后的唯一表示

$a_1,\ldots,a_m$ 无关，添加 $b$ 后相关，则某关系
$$c_1a_1+\cdots+c_ma_m+db=0$$
中 $d$ 必不为零，否则原组相关。于是可以解出 $b$。若又有两种表示，作差得原组的零组合，无关迫使对应系数相同，故表示唯一。

> [!tip] “至少一个”与“每一个”不同
> 相关组 $(e_1,e_2,0)$ 中，零向量能由其他向量表示，但 $e_1$ 无法由 $e_2,0$ 表示。因此相关不能理解为每个向量都多余。
