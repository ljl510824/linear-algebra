# 02-03 伴随矩阵与行列式运算

[[00 线性代数总览]] · [[第二章 矩阵及运算]] · [[阅读与使用说明]]

## 矩阵的行列式

方阵 $A$ 的行列式记 $|A|$ 或 $\det A$，元素位置不变。如 $\det\begin{pmatrix}2&6\\1&4\end{pmatrix}=2$。
$$\det A^T=\det A,\quad\det(kA)=k^n\det A,\quad\det(AB)=\det A\det B=\det(BA).$$
最后一式并不表示 $AB=BA$。

## 伴随矩阵

> [!abstract] 定义与基本恒等式
> $A^*$ 是**代数余子式矩阵的转置**：$(A^*)_{ij}=A_{ji}$。对于 $n\ge2$ 的方阵，无论可逆与否都有伴随矩阵，且
> $$AA^*=A^*A=\det(A)E.$$
> 证明用 [[01-05 余子式与按行列展开]] 的同行展开与异行相乘等于零。

**原稿例：**
$$A=\begin{pmatrix}1&2&3\\2&2&1\\3&4&3\end{pmatrix},\quad |A|=2,\quad
A^*=\begin{pmatrix}2&6&-4\\-3&-6&5\\2&2&-2\end{pmatrix},\quad AA^*=2E.$$

若 $A$ 可逆，
$$A^{-1}=\frac1{|A|}A^*,\quad A^*=|A|A^{-1},\quad A=|A|(A^*)^{-1}.$$
后两式包含逆矩阵时也须有 $|A|\ne0$。

## 原稿公式大总结

| 对象 | 公式及适用条件 |
| --- | --- |
| 行列式 | $\lvert A^T\rvert =\lvert A\rvert $，$\lvert A^{-1}\rvert =\lvert A\rvert ^{-1}$（可逆） |
| 伴随行列式 | $\lvert A^*\rvert =\lvert A\rvert ^{n-1}$，$n\ge2$ |
| 二次转置、逆 | $(A^T)^T=A$，$(A^{-1})^{-1}=A$ |
| 二次伴随 | $(A^*)^*=\lvert A\rvert ^{n-2}A$，$n\ge2$ |
| 逆与转置 | $(A^T)^{-1}=(A^{-1})^T$ |
| 伴随与转置 | $(A^T)^*=(A^*)^T$ |
| 伴随与逆 | $(A^{-1})^*=(A^*)^{-1}$（可逆） |
| 乘积 | $(AB)^T=B^TA^T$，$(AB)^{-1}=B^{-1}A^{-1}$，$(AB)^*=B^*A^*$ |
| 数乘 | $(kA)^T=kA^T$，$(kA)^{-1}=k^{-1}A^{-1}$（$k\ne0$ 且 $A$ 可逆），$(kA)^*=k^{n-1}A^*$ |
| 加法 | $(A+B)^T=A^T+B^T$；一般没有行列式、逆矩阵、伴随矩阵的对应可加公式 |

原稿提醒四类可交换情形：$AE=EA$、$A(kE)=(kE)A$、$AB=E=BA$、$AA^*=A^*A$。其中第三项要求 $A,B$ 为同阶方阵。

## 补例与证明

**奇异时伴随也奇异：** 对 $n\ge2$，若 $|A|=0$，假设 $A^*$ 可逆，由 $A^*A=0$ 可推出 $A=0$，于是 $A^*=0$，矛盾。也可由 $|A^*|=|A|^{n-1}$ 直接得出。

**求伴随阵的逆：** $A=\begin{pmatrix}1&2&0\\2&2&0\\3&4&5\end{pmatrix}$，$|A|=-10$，
$$ (A^*)^{-1}=\frac1{|A|}A=-\frac1{10}\begin{pmatrix}1&2&0\\2&2&0\\3&4&5\end{pmatrix}.$$

**由逆阵求伴随行列式：** $A^{-1}=\begin{pmatrix}2&1&1\\1&2&1\\1&1&2\end{pmatrix}$，其行列式为 4；于是 $|A|=1/4$，$|A^*|=1/16$。

**乘积行列式：** $A,B$ 为 $n$ 阶阵，$|A|=2,|B|=-4$，
$$|2B^*A^{-1}|=2^n(-4)^{n-1}\frac12=(-8)^{n-1}.$$

**组合行列式：** $|A|=2,|B|=-3,|A+B|=5$，则
$$\bigl||A|B^*+|B|A^*\bigr|=5(-6)^{n-1}.$$
推导：括号内为 $|A||B|(B^{-1}+A^{-1})$；再用
$$B^{-1}+A^{-1}=A^{-1}(A+B)B^{-1}$$
取行列式。

> [!tip] 补充：记号说明
> 本库沿用原稿 $A^*$ 表示伴随矩阵，不表示复共轭转置。对于复数矩阵，其他资料常用 $A^*$ 表示共轭转置，阅读时需先核对定义。本讲义主要在实数域讨论。
