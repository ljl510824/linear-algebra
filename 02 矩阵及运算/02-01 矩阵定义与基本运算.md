# 02-01 矩阵定义与基本运算

[[00 线性代数总览]] · [[第二章 矩阵及运算]] · [[阅读与使用说明]]

## 定义与术语

由 $mn$ 个数 $a_{ij}$ 排成的 $m$ 行 $n$ 列数表称为 $m\times n$ 矩阵，记 $A=(a_{ij})_{m\times n}$。它本身是数表，不能像行列式一样直接“算成一个数”；$m,n$ 可以不同。

$$A=\begin{pmatrix}1&2\\3&8\end{pmatrix},\qquad \det A=\begin{vmatrix}1&2\\3&8\end{vmatrix}=2.$$

| 术语 | 原稿说明与例子 |
| --- | --- |
| 方阵 | $m=n$，称 $n$ 阶方阵；一阶阵 $(-8)$ 可与数 $-8$ 对应 |
| 对角阵 | 非对角元全零，如 $\operatorname{diag}(1,2,0)$ |
| 单位阵 | 主对角元为 1，其余为 0，原稿记 $E$，也常记 $I$ |
| 数量阵 | $kE$，如 $2E_3$、$4E_2$ |
| 行、列矩阵 | 只有一行或一列；矩阵也可看成行向量或列向量的组合 |
| 同型矩阵 | 行数、列数分别相同 |
| 相等矩阵 | 同型且对应元素相等 |
| 零矩阵 | 所有元素为零，维数按上下文确定 |
| 矩阵的行列式 | 方阵中元素位置不变，按行列式规则计算 |

矩阵可表示配料、订单与多步关系，见本节末的应用。

## 加减与数乘

同型矩阵对应元素相加减：
$$\begin{pmatrix}2&6&7\\1&2&3\end{pmatrix}+\begin{pmatrix}1&2&6\\1&1&1\end{pmatrix}=\begin{pmatrix}3&8&13\\2&3&4\end{pmatrix},$$
$$A-B=\begin{pmatrix}1&4&1\\0&1&2\end{pmatrix},\qquad
kA=\begin{pmatrix}2k&6k&7k\\k&2k&3k\end{pmatrix}.$$
满足交换、结合律，以及
$$k(A+B)=kA+kB,\quad(k+l)A=kA+lA,\quad k(lA)=(kl)A.$$
原稿将行列式单行可加性与矩阵全元素相加作比较：
$$\begin{vmatrix}1&2&3\\1&2&4\\1&7&6\end{vmatrix}+\begin{vmatrix}1&2&3\\2&1&2\\1&7&6\end{vmatrix}=\begin{vmatrix}1&2&3\\3&3&6\\1&7&6\end{vmatrix},$$
但对应矩阵相加为
$$\begin{pmatrix}2&4&6\\3&3&6\\2&14&12\end{pmatrix}.$$
方阵数乘满足 $\det(kA)=k^n\det A$，一般 $\det(A+B)\ne\det A+\det B$。见 [[01-03 行列式性质与消元计算]]。

## 乘法

> [!abstract] 维数与元素公式
> $$A_{m\times s}B_{s\times n}=C_{m\times n},\qquad c_{ij}=\sum_{k=1}^s a_{ik}b_{kj}.$$
> 左阵列数须等于右阵行数；左边取一行，右边取一列，对应相乘再求和。

$$\begin{pmatrix}1&2&0\\0&2&1\end{pmatrix}
\begin{pmatrix}1&1&0&2\\0&0&1&2\\1&1&2&0\end{pmatrix}
=\begin{pmatrix}1&1&2&6\\1&1&4&4\end{pmatrix}.$$

**例 5：**
$$\begin{pmatrix}4&-1&2&1\\1&1&0&3\\0&3&1&4\end{pmatrix}
\begin{pmatrix}1&2\\0&1\\3&0\\-1&2\end{pmatrix}
=\begin{pmatrix}9&9\\-2&9\\-1&11\end{pmatrix}.$$

**例 6：**
$$A=\begin{pmatrix}-2&4\\1&-2\end{pmatrix},\ B=\begin{pmatrix}2&4\\-3&-6\end{pmatrix};\quad
AB=\begin{pmatrix}-16&-32\\8&16\end{pmatrix},\ BA=0.$$

> [!warning] 矩阵乘法与数乘法的区别
> $AB$ 有意义时 $BA$ 未必有意义；二者都有意义时未必同型；同型时也未必相等。$AB=BA$ 称可交换。$AB=0$ 不能推出 $A=0$ 或 $B=0$；$AB=AC,A\ne0$ 不能推出 $B=C$。

原稿反例：
$$A=\begin{pmatrix}2&0\\-1&0\end{pmatrix},\quad B=\begin{pmatrix}0&0\\1&2\end{pmatrix},\quad C=\begin{pmatrix}0&0\\3&4\end{pmatrix},\quad AB=AC=0\text{ 但 }B\ne C.$$
对 $A=\begin{pmatrix}1&2&6\\2&7&2\end{pmatrix}$，有 $A0_{3\times3}=0_{2\times3}$，$E_2A=AE_3=A$。

乘法满足结合律、对加法的左右分配律、标量结合律：
$$A(BC)=(AB)C,\quad\lambda(AB)=(\lambda A)B=A(\lambda B),$$
$$A(B+C)=AB+AC,\qquad(B+C)A=BA+CA.$$

> [!example] 补充：配料表与订单表
> $A$ 的每行是一种原料、每列是一种产品，元素表示每件产品耗料；$x$ 是产品订单数量，则 $Ax$ 是总用料。若还要把各产品的工序耗时组合进来，矩阵乘法可将“原料—产品—订单”的关系逐层汇总。矩阵的乘法次序必须与关系方向一致。
